# Contributing to ProXP

ProXP should remain a frontend-first PWA.

- Keep PRONOTE protocol logic out of this repository.
- Put API calls in `app.js` or split them into a dedicated `api/` module as the app grows.
- Keep features modular and independent.
- Preserve the PronoteXP glass / mesh visual language.
- Do not store passwords.
- Do not log PRONOTE tokens or student data.
- Test desktop and narrow mobile layouts before merging.
